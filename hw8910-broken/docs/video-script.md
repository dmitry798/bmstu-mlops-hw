# Итоговая запись экрана: 5–8 минут

Реальный захват экрана OBS 1920×1080, MP4, без озвучки, титров и вставок.
На экране — полноэкранный терминал, настоящие команды и документы проекта.

1. Коммиты, семь причин, красные доказательства и исправление release.py.
2. Полный зелёный CI; намеренная поломка в копии; повтор зелёных контрактов.
3. Четыре задачи Prefect; сбой, Cached в новом процессе, изменение входа.
4. Неполный/чужой/отклонённый отчёт, SHA до/после; сбой pointer/journal.
5. Один release event после повторов; live HTTP A → B → A с перезапусками.
6. Baseline manifest и её происхождение; кандидат, runtime и полные метрики.
7. Реальный отказ gate и Prefect; SHA принятого указателя до/после.
8. FastAPI health/ready, реальный ответ, неправильный лимит без вызова backend.
9. Перезапуск реального API; те же model_id/runtime после загрузки.
10. Три триггера: код/данные/адаптер — docs/video-review.txt.
11. Настоящий benchmark 8+8, raw JSONL, сравнительная таблица.
12. docs/measurements-final.md: очередь/compute, prefill/decode, KV-cache,
    TTFT/ITL не измерялись, p95 не оценивается, SGLang/vLLM не сравнивались.
13. docs/artifact-access.md: публичная baseline, отдельный архив данных/отчётов,
    проверка SHA256SUMS, ограничения доступа к локальному MLflow кандидата.

Новый benchmark сохраняется в свежем .experiments/screen-*/benchmark/.
В ходе записи scripts/finalize_screen_evidence.py проверяет 16 попыток,
переносит точные результаты в docs/real/benchmark-final/, обновляет отчёт
и собирает отдельный evaluation-artifacts-final.tar.gz без весов.

MP4 и архив из docs/video/ прикладываются отдельно, они исключены из Git.
Прежние видео и результаты не удаляются. Внешней публикации и push нет.
